#  PulseCare

### Location-Based Healthcare Discovery Platform

PulseCare is a healthcare-focused web application designed to help users discover **doctors and hospitals based on their location** through a simple and user-friendly interface.

The project was built to explore how location-based services can make healthcare discovery faster and more convenient.

##  Problem

Finding nearby doctors and hospitals quickly can be difficult, especially when users need healthcare services in an unfamiliar location.

PulseCare aims to provide a simple digital solution for discovering relevant healthcare services based on location.
